# ADR-008: HPA para a API

- Status: Proposed
- Data: 2026-09-08

## Contexto
A API já possui HPA baseado em CPU e memória, com requests/limits definidos.

## Decisão
Manter HPA `autoscaling/v2`, inicialmente com mínimo 2 e máximo 5 réplicas, CPU alvo de 70% e memória alvo de 75%, sujeitos à calibração por métricas reais.

## Alternativas consideradas
Escala fixa reduz a complexidade, mas não atende à escalabilidade esperada. KEDA não é necessário sem eventos ou filas.

## Consequências
Metrics Server ou equivalente será obrigatório. Os valores são baseline inicial, não promessa de capacidade sem teste de carga.
